## 1. 레퍼런스에서 가져올 것 · 가져오지 않을 것

**가져올 것**

1. **왼쪽 정렬 큰 제목 + 그 아래 흐린 한 줄**(ref2) — 머리: '바이어 리스크 한눈에' + '기준일 · 데이터 범위' 한 줄.
2. **구역 머리 줄**(ref2) — 구역 제목은 왼쪽, 오른쪽 끝에 작은 보조 정보(예: '위험 선 17% 기준' · '큰 순서'). 구역 사이는 넉넉한 여백으로 나눈다.
3. **같은 크기 칸의 격자와 일정한 간격, 칸 안의 2단 글자 위계**(ref1 · ref2) — 굵은 이름(또는 큰 숫자) 한 줄 + 흐린 보조 줄 한 줄. KPI 4칸과 휴대폰의 위험 상위 카드에 쓴다.

**가져오지 않을 것**

1. **그림 · 썸네일 · 로고 · 사이트 글** — 작품 이미지(ref1), 앱 화면 캡처와 앱 로고(ref2), 영어 문구.
2. **색** — ref1의 파랑 강조 제목 글자, ref2의 어두운 바탕과 노란 단추. 색은 아래 우리 토큰으로 정한다.
3. **'AI 티'에 걸리는 모양** — ref1의 가운데 정렬 큰 제목과 양옆에 떠 있는 장식 그림 · 로그인 칸, ref2의 크게 둥근 카드 모서리(8px 넘음).

## 3. 레이아웃 뼈대

구역 순서는 두 폭 모두 같다: **머리 → KPI 4개 → 신호등 등급 분포 + 위험 선 슬라이더 → 위험 상위 10 → 지역별 채권 → 바닥글**

### 넓은 화면 (1280px)

| 구역 | 배치 |
|---|---|
| 머리 | 가운데 내용 폭 최대 1216px(좌우 `space-6`). 제목(`fs-5`, 굵게) 왼쪽 정렬, 아래 한 줄(`fs-1`, `color-text-muted`): 기준일 2026-09-30 · (가상) 한빛정밀(주) 바이어 150곳 · 합성 데이터 |
| KPI 4개 | 4칸 가로 한 줄(같은 폭), 간격 `space-5`. 칸마다 이름(`fs-1`, 보조) → 숫자(`fs-6`, 굵게, 한 줄) → 보조 줄(`fs-1`) |
| 등급 분포 + 슬라이더 | 2칸: 왼쪽 2/3 등급 분포(가로 막대 하나 + 등급별 곳 수 · 채권 표), 오른쪽 1/3 위험 선 슬라이더(5–30%, 지금 값 `color-accent`) + '처음 17%보다 …' 한 줄 |
| 위험 상위 10 | 표 한 개, 열: 바이어 이름 · 나라 · 등급 · 위험 점수 · 채권 · 연체 · 위험 신호. 글은 왼쪽, 숫자는 오른쪽 정렬, 줄 사이 1px 구분선 |
| 지역별 채권 | 지역 6줄 가로 막대(큰 순서). 줄마다 지역 이름(왼쪽) · 막대 · 금액(오른쪽). C등급 몫은 `grade-c`, 나머지는 `color-border` |
| 바닥글 | `fs-1`, 보조 글자, 왼쪽 정렬: '(가상) 합성 데이터 · 기준일 2026-09-30 · 위험 점수는 판단을 돕는 값이고 결정은 사람이 합니다' |

### 휴대폰 (390px)

| 구역 | 배치 |
|---|---|
| 머리 | 좌우 여백 `space-4`. 제목 `fs-5` 그대로, 설명 한 줄은 줄바꿈 허용(숫자 가운데서는 줄바꿈 없음) |
| KPI 4개 | 2 × 2 격자, 간격 `space-3`. 숫자는 `fs-5`(한 단계 줄임), 그래도 넘치면 `fs-4` |
| 등급 분포 + 슬라이더 | 위아래로: 등급 막대 → 등급별 곳 수 · 채권 → 슬라이더(손잡이 44px 이상) → '처음 17%보다 …' 한 줄 |
| 위험 상위 10 | 표 대신 카드 10장, 한 줄에 하나. 카드: 1줄 이름(`fs-3`, 굵게) + 등급 라벨(오른쪽) · 2줄 나라 · 위험 점수 · 3줄 채권 · 연체(오른쪽 정렬) · 4줄 위험 신호(`fs-1`, 보조) |
| 지역별 채권 | 넓은 화면과 같은 가로 막대, 지역 이름과 금액은 막대 위 한 줄에 |
| 바닥글 | 넓은 화면과 같음 |

가로 스크롤 없음 · `word-break: keep-all` · 금액 · %는 `white-space: nowrap`.

## 4. 'AI 티' 금지 목록

| 금지 | 대신 |
|---|---|
| 보라 · 파랑 그라데이션 | 흰색 · 연회색 바탕 + 강조 1색 |
| 이모지 아이콘 | 글자 라벨, 꼭 필요하면 선 아이콘(SVG) |
| 모든 카드에 그림자 | 1px 테두리나 바탕색 차이 |
| 유리(blur) 효과 남발 | 불투명한 면 |
| 가운데 정렬 일색 | 글은 왼쪽, 숫자는 오른쪽 정렬 |
| 'Welcome back!' 같은 빈말 | 기준일 · 데이터 범위처럼 쓸모 있는 한 줄 |
| 무지개색 차트 | 회색 + 뜻이 있는 1–2색(등급 색) |
| 지나치게 둥근 모서리 | 4–8px |
| 의미 없는 장식 그림 | 빈칸(여백) |
| 영어 더미 글 | 우리말 진짜 문장 |
