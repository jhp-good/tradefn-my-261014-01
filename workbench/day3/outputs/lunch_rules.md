# 한빛식당(가상) 점심 기록 — 정제 규칙

- 원본: `labs/day3/lab-c/hanbit_lunch_log.csv` (UTF-8 BOM, 읽기만 함)
- 코드: `scripts/lunch_clean.py` — 이 표 그대로, 이 표의 **위에서 아래 순서로** 적용한다
- 결과: `workbench/day3/outputs/lunch_clean.csv` · 규칙별 줄 수는 `workbench/day3/outputs/lunch_clean_log.md`
- 기준: `labs/day3/lab-c/lab_c_guide.md` 「4. 정제 규칙」
- R10은 나중에 더한 규칙이라 번호는 10이지만, R6가 출근예정을 쓰므로 R6보다 먼저 적용한다.

| 번호 | 규칙 | 왜 |
|---|---|---|
| R1 | 날짜를 `YYYY-MM-DD`로 바꾼다 — `2026.3.2` · `2026/03/02` · `3월 2일`. 연도가 없으면 10–12월은 2025년, 1–9월은 2026년 | 날짜 형식이 네 가지로 섞여 있으면 정렬 · 같은 날짜 찾기 · 요일 계산을 할 수 없다. 기록 기간이 2025-10 ~ 2026-10이라 연도 없는 날짜는 월로 연도를 정한다 |
| R2 | 요일은 적힌 글자를 버리고 날짜에서 다시 계산한다(월 · 화 · 수 · 목 · 금) | `수요일` · `Mon`처럼 표기가 섞였고, 적힌 요일이 실제 요일과 다른 줄도 있다. 날짜가 기준이다 |
| R3 | 비고가 `휴무`인 줄은 뺀다 | 휴무 날은 출근예정 · 식수가 0이라 식수 예보를 배울 재료가 아니다 |
| R4 | 같은 날짜가 두 줄이면 비고에 `재집계`가 든 줄을, 없으면 나중 줄을 남긴다 | 하루는 한 줄이어야 한다. 재집계 줄이 바로잡은 값이고, 표시가 없으면 나중에 적은 줄을 믿는다 |
| R5 | 식수가 빈칸인 줄은 뺀다(지어내지 않는다) | 식권 기계 고장으로 집계하지 못한 날이다. 예보할 숫자를 지어내면 결과가 오염된다 |
| R10 | 출근예정 빈칸은 같은 요일의 바로 앞 기록 4개(출근예정이 있는 줄)의 가운데 값(median)을 반올림해 채운다 | 식수는 있는데 출근예정만 빠진 날이다. R6 판정과 '100명당 식수'에 출근예정이 필요하고, 요일마다 출근 인원이 비슷하므로 가까운 같은 요일의 가운데 값이 튀는 값에 덜 흔들린다 |
| R6 | 식수가 출근예정보다 많거나 출근예정의 20% 미만이면 그 줄을 뺀다. **비고가 `수기 집계`인 줄 — 수강생 결정: '수기 집계' 줄은 뺀다. 이유: 프롬프트에 적힌 이유 없음(확인 필요)** | 출근한 사람보다 많이 먹거나 다섯 명 중 한 명도 안 먹는 날은 기록 실수(오타 · 자릿수 빠짐)로 보인다. '수기 집계' 줄은 고칠지 뺄지 사람이 정한다 |
| R7 | 날씨는 맑음 · 흐림 · 비 · 눈 넷으로 — `맑` · `sunny` → 맑음 / `구름많음` · `cloudy` → 흐림 / `rain` · `우천` · `소나기` · `흐리고 비` → 비 / `snow` → 눈 / 빈칸 → 모름 | 같은 날씨가 여러 표기로 흩어지면 '비 오는 날' 같은 비교와 모델의 0/1 열이 쪼개진다 |
| R8 | 최고기온은 `℃` · `°C` · 공백을 떼고 숫자만 남긴다(빈칸은 빈칸으로 둔다) | 단위가 붙으면 숫자로 계산할 수 없다. 빈칸은 지어내지 않는다 |
| R9 | 이름 통일 — `돈까스` → 돈가스 · `카레라이스` → 카레 · `제육` → 제육볶음 · `치킨마요덮밥` → 치킨마요 · `김치 찌개` → 김치찌개 · `외부손님` → 외부 손님 방문 · `전사교육` → 전사 교육 | 같은 메뉴 · 행사가 두 이름으로 나뉘면 메뉴별 비교와 모델의 열이 쪼개진다 |

마지막 정리: 월급날 `Y` → 1 · 빈칸 → 0, 출근예정 · 식수는 정수, 날짜순 정렬, UTF-8 BOM, 열은 원본과 같은 10개.
